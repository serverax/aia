Features

✨ Animated Factory

Four floating machines (⚙️ 🤖 🔧 📊) orbiting a pulsing central sphere. The orbital ring rotates continuously.

📋 Waitlist Form

Beautiful form collecting: Name, Email, Profession (dropdown), Company. Real-time validation and error messages.

🎯 Live Signup Count

Shows current position on waitlist (e.g., "#1,542 people ahead"). Updates every 30 seconds from API.

📊 Stats Section

Display key metrics: 99.9% Uptime SLA, 1000+ Metrics/sec, 50ms Alert Latency, 100% Kubernetes Native

🎨 Feature Cards

6 feature cards showing: Real-Time Monitoring, Predictive Analytics, Autonomous Control, Cloud Native, Enterprise Security, Scalable Infrastructure

🎭 Smooth Animations

All elements animate smoothly on load: text fades in, cards slide up, factory machines float, orb pulses.

📱 Responsive Design

Works perfectly on desktop, tablet, and mobile. All animations optimized for performance.

Access Options

Local Development

cd /mnt/f/aia/landing-page
python -m http.server 8000

# Open: http://localhost:8000

Docker

cd /mnt/f/aia/backend/waitlist
docker-compose up

# Open: http://localhost

Kubernetes

kubectl apply -f backend/waitlist/k8s.yaml

# Access: https://aia.ordinoxai.com
